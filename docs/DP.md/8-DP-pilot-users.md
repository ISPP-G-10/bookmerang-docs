# 2. Tipos de usuarios piloto

Se han definido distintos perfiles de usuarios con el objetivo de representar diferentes motivaciones y comportamientos de lectura dentro del sistema **Bookmerang**.

- **Usuario A — Lector Estudiante / Económico**  
  Busca principalmente libros académicos y también best-sellers. Es sensible al ahorro económico y al ahorro de espacio físico.

- **Usuario B — Lector Ecológico**  
  Motivado por la sostenibilidad. Quiere dar una segunda vida a sus libros y no le importa leer libros usados.

- **Usuario C — Lector Económico**  
  Interesado en leer libros populares evitando pagar el precio completo de un libro nuevo.

- **Usuario D — Lector Social**  
  Motivado por la gamificación, el descubrimiento de nuevas historias y la interacción con otros lectores.
